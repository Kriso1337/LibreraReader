# Android: книжная полка и каталог

Первый этап реализации после выбора варианта «Книжная полка», 2 ноября 2026 года. Целевой размер — стандартный Android-планшет 10–12″, обе ориентации.

## Что изменено

- Новая вкладка «Каталог» (стабильный ID 8). Миграция добавляет её один раз, сохраняет порядок и скрытые вкладки пользователя. Существующая библиотека, читалка, TTS и остальные функции остаются доступны.
- Настоящие страницы OPDS: переходы по разделам, поиск OpenSearch, пагинация, описания и предлагаемые источником форматы. Каталог загружается по страницам; массового скачивания нет.
- Изолированный HTTPS-клиент, известные зеркала, ограниченный автоматический переход между ними и явный ручной выбор. Произвольные URL из форума не добавляются автоматически.
- Дисковый кеш страниц с отметкой времени. Режим офлайн показывает сохранённые результаты; новую загрузку и повтор он не запускает. Книги, уже сохранённые на устройстве, открываются существующей читалкой.
- Сохраняемая SQLite-очередь + WorkManager: прогресс, отмена, повтор и ожидание сети. После закрытия экрана задача продолжает принадлежать WorkManager. Завершённые файлы регистрируются в локальной библиотеке, незавершённая регистрация восстанавливается.
- Внутренняя папка приложения или выбранная через системный picker папка SAF. Внутренние книги удаляются при удалении приложения; это подписано в интерфейсе. Существующие файлы не перезаписываются.
- Проверка содержимого EPUB, FB2/FB2.ZIP, PDF, MOBI/AZW/AZW3 и DjVu до публикации локального файла. Ответ HTML с HTTP 200 не становится книгой. Предел файла — 512 MiB; DTD, подозрительные архивы и неподдерживаемые ссылки отклоняются.

## Планшетная компоновка

Порог определяется доступной шириной окна в dp, а не диагональю. Обычный планшет 1280×800 dp показывает полку слева и карточку справа; 800×1280 dp — широкую полку и отдельную карточку. Карточка имеет ширину 360–440 dp, обложки сохраняют пропорции. Сетка занимает от 1 до 6 колонок и уменьшает их количество при увеличении шрифта. При 200% шрифте порог двух панелей повышается до 1176 dp. Двум панелям также требуется не менее 480 dp доступной высоты. Это же правило действует в разделённом окне; короткий альбомный экран телефона использует компактные карточки.

Тёплый фон, зелёные акценты, заголовки с засечками и тёмная тема соответствуют выбранной концепции. Основные кнопки имеют область нажатия не меньше 48 dp. Поиск, выбранная книга/формат и положение списка сохраняются при пересоздании фрагмента.

## Воспроизведение сборки

Checkout upstream содержит абсолютные symlink на JNI-библиотеки машины автора. Для локальной проверки использованы шесть общих JNI-библиотек из официального релиза **10.0.22 FdroidJS universal** (все четыре ABI), через внешний Gradle init script с переопределением `fdroidJS.jniLibs.srcDirs`. MuPDF не подмешивался. Сами бинарники и SDK в репозиторий не добавлены.

Источник: [официальный APK 10.0.22](https://github.com/foobnix/LibreraReader/releases/download/10.0.22/Librera.FdroidJS-10.0.22-uni.apk). SHA-256: `c476b48d63ddc2a2aefcf1147020c615e30e618fa911ff5a4b391b6c19442b97`.

Требуются JDK 21, Android SDK 37, build-tools 36.0.0 (выбран AGP), исходные зависимости проекта и доступные JNI. В локальном init script для F-Droid отключена задача `processFdroidJSDebugGoogleServices` — у fork нет закрытого `google-services.json`; рекламные/Drive placeholders пустые, release-параметры указаны как стандартный debug keystore. Для preview APK локально добавлен `applicationIdSuffix = ".catalogpreview"`, чтобы его можно было установить отдельно от обычной Librera. Эти локальные настройки не меняют сборку upstream и не являются production-подписью.

Основные задачи:

```sh
./gradlew :app:testFdroidJSDebugUnitTest --tests 'com.foobnix.catalog.*' \
  :app:assembleFdroidJSDebug :app:assembleFdroidJSDebugAndroidTest
```

Нативные классы тестов: `com.foobnix.catalog.ui.CatalogPhoneDeviceTest`, `com.foobnix.catalog.ui.CatalogTabletDeviceTest`, `com.foobnix.catalog.CatalogParserDeviceTest`, `com.foobnix.ui2.ContextFontScaleDeviceTest`, `com.foobnix.catalog.CatalogDownloadDeviceTest`. Живая передача одной книги общественного достояния включается только аргументом instrumentation `catalogLive=true`.

## Что остаётся следующим этапом

Полная оболочка «Читаю / Мои книги / Каталог / Ещё» и редизайн reader пока представлены прототипом. Новая вкладка внедрена в существующую оболочку.

Побайтовая пауза/докачка не реализована: отмена и повтор начинают передачу заново. Android ограничивает фоновые задания; работа в фоне не обещает обход системных квот. Форум резервных адресов остаётся ручным способом поиска новых зеркал. Автоматического доверия новым доменам, Tor-прокси и HTML-fallback пока нет.

До выпуска нужны проверки на физическом планшете 10–12″, SAF/SD-карте с отзывом разрешений и нехваткой места, восстановление после принудительного завершения процесса, TalkBack/RTL, а также остальные build flavors и полноценная матрица открытия форматов. Пройденные локальные тесты не подменяют эти проверки.
