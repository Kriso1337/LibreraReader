# Librera — направление редизайна

Статус: проект интерфейса для обсуждения, 2 ноября 2026. Android-реализация — следующий этап.

## Основная идея

Librera становится спокойным местом для чтения, где локальная библиотека и поиск новых книг связаны одним понятным действием: «Скачать в мои книги». Читатель всегда понимает, какие книги уже на устройстве, а какие пока доступны только в каталоге.

Основное направление — **«Книжная полка»**: выразительные обложки, просторные интервалы, тёплая бумажная поверхность и зелёный акцент. Альтернатива — **«Компактный каталог»**: строки с автором, названием и форматами для пользователей с большой библиотекой. Обе композиции сохраняют одинаковые действия и навигацию.

## Карта экранов

| Раздел | Основная задача | Что переносится из Librera |
|---|---|---|
| Читаю | Продолжить последнюю книгу | Недавние книги и прогресс |
| Мои книги | Найти сохранённую книгу | Локальная библиотека, папки, избранное, коллекции, фильтры |
| Каталог | Найти и скачать книгу | OPDS, поиск по каталогу; отдельный источник Флибуста |
| Ещё | Настроить приложение и доступ | Настройки, облака, синхронизация, другие каталоги и инструменты |

Очередь загрузок открывается из верхней панели каталога. После сохранения книга появляется в «Моих книгах», а действие в карточке меняется на «Читать». «Закладки», заметки, TTS, режим музыканта и настройки вёрстки остаются доступными из читалки; сокращение нижней навигации не удаляет эти функции.

## Визуальные правила

- Заголовки книжных подборок и названия на обложках — антиква; навигация, формы, статусы и метаданные — системный sans-serif. В Android использовать масштабирование текста системы.
- Рабочая шкала отступов: 4 / 8 / 12 / 16 / 24 / 32 dp. Основной горизонтальный отступ — 20–24 dp, на узком экране — 16 dp.
- Основной текст — 16 sp, второстепенный — 14 sp, подписи навигации — не менее 12 sp. Отдельно проверить 200% font scale: строки и панели должны расти по высоте.
- Тап-зоны Android — минимум 48 dp. Выбранные состояния обозначать и цветом, и текстом/формой. Не использовать только зелёную точку как сообщение о доступности.
- Основное действие в карточке книги одно: «Скачать» или «Читать». Избранное, выбор формата и папки — вспомогательные действия.
- Обложка не нужна для идентификации: при её отсутствии показывать авторское имя, название и спокойную типографическую заглушку. Прототип использует такие демонстрационные обложки.
- При сетевой ошибке сохранять результаты и положение списка. Сообщение и повторная попытка занимают небольшой блок, а не заменяют весь интерфейс пустым экраном.
- Поддержать светлую и тёмную схемы, системную тему и уменьшение анимации. Настройка темы чтения независима от темы приложения.

Предлагаемые базовые токены; окончательные оттенки сверяются по результатам Android accessibility-проверок:

| Токен | Светлая схема | Тёмная схема |
|---|---|---|
| Фон | `#F7F5EE` | `#181E1B` |
| Поверхность | `#FFFEF9` | `#232C27` |
| Основной текст | `#243C31` | `#EDF1E6` |

## Сценарий каталога

1. Открыть вкладку «Каталог». Источник виден в компактной кнопке «Флибуста». Для выбора зеркала открыть настройки источника.
2. Искать по названию или автору. Данные загружаются постранично; скачивание полного каталога не требуется. Фильтр применяется на сервере только при поддержке источником; локальный фильтр должен явно обозначать свою область.
3. Открыть карточку: обложка, автор, название, аннотация, язык, серия и доступные форматы. Не показывать пустые строки метаданных и не выдумывать размеры файлов.
4. Выбрать предлагаемый источником формат. Предпочтительный формат можно запомнить, но недоступный формат нельзя предлагать как доступный.
5. Нажать «Скачать». При первом использовании выбрать папку; далее показывать её краткое имя и возможность изменения.
6. Видеть понятный статус: очередь, загрузка, ожидание сети, ошибка или готово. При неизвестной длине файла показывать переданные байты без выдуманного процента.
7. Открыть сохранённую книгу. Она доступна из «Моих книг» после перезапуска и без сети.

В прототипе поиск, форматы, размеры и прогресс демонстрационные. Реальная загрузка будет предлагаться только для файлов, которые источник фактически отдаёт; обещание скачать абсолютно любую запись каталога технически невыполнимо.

## Состояния, которые нельзя потерять в реализации

| Событие | Что видит читатель | Действие |
|---|---|---|
| Нет сети, есть кеш | Результаты с отметкой сохранённой версии | Читать локальные книги, повторить запрос |
| Нет сети и кеша | Короткое объяснение | Повторить, перейти в «Мои книги» |
| Зеркало не отвечает | «Проверяем другой адрес» | Отмена, выбор источника |
| Поиск ничего не нашёл | Запрос и пустой результат | Изменить запрос, сбросить фильтр |
| Файл уже сохранён | «На устройстве» | Читать или выбрать другой формат |
| Не хватает места | Загрузка остановлена, указан размер если известен | Освободить место, повторить |
| Доступ к папке отозван | Имя папки и причина остановки | Выбрать папку заново |
| Файл отсутствует у источника | «Этот файл сейчас недоступен» | Другой формат, повторить позднее |
| Нужна авторизация или ответ CAPTCHA | Явное сообщение источника | Настройки доступа; не сохранять HTML как книгу |

## Как провести редизайн целиком без потери функций

1. Ввести оболочку и общие компоненты: навигацию, поиск, карточки, меню и состояния ошибок. Сделать таблицу соответствия всех старых пунктов новым.
2. Перенести библиотеку, папки, избранное и недавнее; сохранять пути, разрешения, метаданные и прогресс. Миграция должна быть обратимой на уровне настроек интерфейса.
3. Перенести настройки по задачам, добавить поиск настроек. Экспертные параметры оставить доступными, не прятать за удалением функций.
4. Обновлять элементы управления читалкой отдельно. Сначала новая панель и меню; затем точечная работа с типографикой. Движки PDF/EPUB/DjVu, TTS, закладки и аннотации требуют собственной регрессии.
5. Проверить планшет и landscape: navigation rail и двухпанельная библиотека как отдельный адаптивный вариант. Мобильный прототип не доказывает готовность планшетной версии.

## Проверка решения с пользователем

Попросить выполнить без подсказок: найти книгу по автору, выбрать формат, сохранить, найти без сети, поменять папку и восстановить неудачную загрузку. Фиксировать места остановки и ошибочные нажатия. Успех — человек отличает онлайн-запись от локального файла и может продолжить чтение без помощи.

Следующие дизайн-решения для проверки на устройстве: плотность списка, расположение фильтров, размер обложек, читаемость подписей нижней навигации и доступность редких функций. Эти решения не блокируют прототип, но должны быть проверены до массового переноса экранов.
